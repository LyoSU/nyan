# 🐱 НЯН Docker Setup - Підсумок

## 📦 Створені файли для Docker розгортання:

### Основні файли:
- `Dockerfile` - основний образ з усіма залежностями  
- `docker-compose.yml` - конфігурація сервісів (без MongoDB)
- `docker-entrypoint.sh` - entrypoint для підстановки змінних
- `.dockerignore` - файли що виключаються з образу

### Конфігурація:
- `.env.example` - приклад змінних середовища
- `configs/mongo_config.json.template` - шаблон конфігурації MongoDB

### Скрипти управління:
- `start-docker.sh` - запуск НЯН
- `stop-docker.sh` - зупинка НЯН  
- `test-docker.sh` - тестування налаштувань

### Документація:
- `DOCKER_README.md` - детальні інструкції

## 🚀 Як користуватися:

### 1. Створіть .env файл:
```bash
cp .env.example .env
nano .env  # відредагуйте налаштування вашого MongoDB
```

### 2. Налаштуйте Telegram API:
Відредагуйте `configs/client_config.json`

### 3. Налаштуйте список каналів:
Відредагуйте `channels.json`

### 4. Протестуйте:
```bash
./test-docker.sh
```

### 5. Запустіть:
```bash
./start-docker.sh
```

## 🔧 Особливості:

- **Без MongoDB** - підключається до зовнішнього сервера
- **Автоматична конфігурація** - змінні з .env підставляються автоматично
- **3 сервіси**: app (дебаг), crawler (парсинг), sender (відправка)
- **Автоперезапуск** - всі сервіси автоматично перезапускаються при падінні
- **Логи** - доступні через `docker-compose logs -f`

## ⚠️ Важливо:

1. Ваш MongoDB сервер має бути доступний з Docker контейнерів
2. Переконайтеся що налаштовано файрвол і мережу  
3. Для cloud серверів можливо потрібно додати IP до whitelist
4. Всі конфігураційні файли мають бути налаштовані перед запуском

## 📞 Команди для управління:

```bash
# Запуск
./start-docker.sh

# Тестування  
./test-docker.sh

# Зупинка
./stop-docker.sh

# Логи
docker-compose logs -f

# Статус
docker-compose ps
```
